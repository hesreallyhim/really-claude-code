# Skill Identification

Analyzes user objectives to identify and recommend optimal skill combinations for completing tasks effectively. Provides skill gap analysis, pattern-based recommendations, and workflow design.

## Directory Structure

```
skill-identification/
├── SKILL.md                              # Main skill instructions (start here)
├── README.md                             # This file
├── references/
│   ├── skill-patterns.md                 # Skill combinations by domain
│   └── skill-templates.md                # Templates for creating new skills
└── scripts/
    ├── skill-analyzer.py                 # Automated requirement analysis
    └── validate-identification.py        # Validation test suite
```

See `SKILL.md` for full usage instructions.
